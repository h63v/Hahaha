# MangaX — GitHub Pages

هذه نسخة Static مناسبة لـ GitHub Pages.
لا تحتاج Netlify أو Build أو Node.js أو PHP.

الملفات الأساسية:
- index.html: الصفحة الرئيسية
- style.css: التصميم
- script.js: قائمة الأعمال والبحث والتصنيف
- solo-leveling.html: صفحة العمل
- solo-leveling-chapter-N.html: ملفات الفصول

## إضافة عمل
أضف ملفًا مثل `one-piece.html` ثم أضف بياناته داخل مصفوفة `works` في `script.js`.
وأضف رابط العمل في نفس المصفوفة.

## إضافة فصل
أضف ملفًا مثل:
`one-piece-chapter-1.html`
ثم أضف رابطه إلى صفحة `one-piece.html`.

## GitHub Pages
ارفع الملفات إلى repository ثم:
Settings → Pages → Deploy from a branch → main → / (root) → Save.
